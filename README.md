I started on Android, writing Kotlin with MVVM and Clean Architecture at KlikDokter, Telkom Indonesia, and Komerce. The features I built shipped into apps people open every day.

Now I'm an AI Engineer at an AI agency in Jakarta. My day job is building AI pipelines that run themselves, from the webhook coming in to the output going out.

Lately I've spent a lot of time researching AI agents for different use cases: bug bounty, trading automation, LP automation, and a few more still in the works.

The Android habits carried over. Clean structure, error handling I take seriously, and systems that hold up when nobody is watching. My AR e-commerce research was published in JINTEKS.
